# Paquete inicial de configuración SDD para Codex

1. Crea un repositorio vacío/local para el Gestor Académico Docente.
2. Extrae el contenido de este paquete en la raíz del proyecto (conservando directorios y archivos ocultos).
3. Lee y aprueba `.specify/memory/constitution.md`. Aún es borrador.
4. Abre la carpeta del proyecto en VS Code y accede a la extensión de Codex.
5. Pide a Codex: «Lee AGENTS.md y la constitución; presenta un plan de especificaciones y criterios de aceptación sin programar todavía».
6. Solo después de aprobar, instala .NET 10 y el template Avalonia y crea la solución en esta misma carpeta.
7. Audita individualmente cualquier skill de terceros antes de instalarla.

Importante: los archivos `.db`, tokens y datos personales reales no deben llegar a GitHub.

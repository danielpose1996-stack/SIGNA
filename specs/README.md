# Especificaciones SDD

Crear una carpeta por módulo: `001-materias`, `002-importacion-estudiantes`, `003-notas`, `004-rubricas`, `005-asistencias`, `006-informes`, `007-respaldos`.

Cada módulo debe documentar:
- Problema y objetivo
- Historias de usuario y flujos
- Reglas de negocio y validaciones
- Criterios de aceptación (Dado/Cuando/Entonces)
- Estados de UI (sin datos, cargando, éxito, error)
- Modelo de datos y migraciones, si aplica
- Seguridad y tratamiento de errores
- Pruebas de aceptación y unitarias
- Decisiones abiertas (no inventar reglas)

Primero aprobar el alcance y el diseño; luego planificar y desarrollar por incrementos pequeños.

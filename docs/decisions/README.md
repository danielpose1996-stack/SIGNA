# Registro de decisiones arquitectónicas

Sin decisiones nuevas aprobadas en esta preparación. El stack indicado en el paquete es el punto de partida; las propuestas de detalle están en `../arquitectura.md`.

Crear un archivo numerado cuando haya una decisión real que registrar, con: estado (propuesta/aprobada/sustituida), fecha, contexto, alternativas, decisión, consecuencias y referencia a la aprobación del docente. No usar este registro para convertir una regla académica pendiente en un supuesto técnico.
